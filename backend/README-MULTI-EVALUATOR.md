# 다중 평가기 시스템 - 문제 감지 상세 가이드

## 📋 "다중 평가기에서 문제 감지" 의미

### 🔍 개요

"다중 평가기에서 문제 감지 (X개)"는 여러 개의 평가기가 동일한 상품에서 검색 키워드와의 관련성 문제를 발견했을 때 표시되는 메시지입니다.

### 🎯 평가기 종류

1. **규칙 기반 평가기** (Rule-Based Evaluator)

   - 카테고리, 브랜드, 가격 등 메타데이터 기반 평가
   - 예시 이유: `"키워드 매칭 불일치, 카테고리 매칭 불일치"`

2. **키워드 기반 평가기** (Keyword Evaluator)

   - 상품명에서 키워드 직접 매칭 평가
   - 예시 이유: `"상품명에서 '반팔티' 키워드와 관련성 부족 (유사도: 0.42, 최종점수: 0.28)"`

3. **LLM 평가기** (LLM Evaluator)

   - GPT-4o를 사용한 스크린샷 기반 평가
   - 예시 이유: `"This product is not related to '후드티' search term because it is not a hoodie"`

4. **임베딩 기반 평가기** (Embedding Evaluator)

   - 의미적 유사도 기반 평가
   - 예시 이유: `"의미적 유사도 낮음 (임베딩 유사도: 0.38, 임계값: 0.4 미만)"`

5. **개별 이미지 LLM 평가기** (Individual Image LLM)
   - 각 상품 이미지를 개별적으로 LLM 평가
   - 예시 이유: `"상품 이미지가 검색 키워드와 관련성 없음 (관련성 점수: 2.1/5.0)"`

### 📊 문제 감지 예시

#### 단일 평가기 문제 감지

```
요약: "키워드 기반 평가기에서 문제 감지"
상세: • 키워드 기반 평가기: 상품명에서 '반팔티' 키워드와 관련성 부족 (유사도: 0.42, 최종점수: 0.28)
```

#### 다중 평가기 문제 감지 (2개)

```
요약: "다중 평가기에서 문제 감지 (2개)"
상세:
• 키워드 기반 평가기: 상품명에서 '반팔티' 키워드와 관련성 부족 (유사도: 0.42, 최종점수: 0.28)
• 임베딩 기반 평가기: 의미적 유사도 낮음 (임베딩 유사도: 0.38, 임계값: 0.4 미만)

💡 여러 평가기에서 동일한 상품의 문제를 감지했습니다.
   이는 해당 상품이 검색 키워드와 관련성이 낮을 가능성이 높음을 의미합니다.
```

#### 다중 평가기 문제 감지 (3개)

```
요약: "다중 평가기에서 문제 감지 (3개)"
상세:
• 규칙 기반 평가기: 키워드 매칭 불일치, 카테고리 매칭 불일치
• 키워드 기반 평가기: 상품명에서 '후드티' 키워드와 관련성 부족 (유사도: 0.35, 최종점수: 0.22)
• LLM 평가기: This product is not related to '후드티' search term because it is a different type of clothing
```

### 🔧 임계값 설정

각 평가기마다 문제 상품으로 분류하는 임계값이 다릅니다:

- **규칙 기반**: 종합 점수 < 0.5
- **키워드 기반**: 최종 점수 < 0.3
- **임베딩 기반**: 유사도 < 0.4
- **LLM 기반**: GPT가 관련성 없음으로 판단
- **개별 이미지 LLM**: 관련성 점수 < 3.0/5.0

### 📈 신뢰도 해석

- **1개 평가기**: 해당 평가기의 특성상 문제 감지 (추가 검토 권장)
- **2개 평가기**: 상품 관련성에 문제가 있을 가능성 높음
- **3개 이상**: 명확히 관련성 없는 상품으로 판단 가능

### 🎨 UI 표시 개선사항

1. **시각적 구분**: 오렌지색 테두리와 배경으로 강조
2. **평가기 개수 표시**: "2개 평가기" 배지로 명확한 정보 제공
3. **상세 이유 표시**: 각 평가기별 구체적인 판단 근거 제공
4. **도움말 추가**: 다중 평가기 감지의 의미 설명

이러한 시스템을 통해 검색 결과의 품질을 더욱 정확하고 상세하게 평가할 수 있습니다.
